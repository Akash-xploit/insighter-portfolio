# in$1ghter

Personal portfolio of **Akash Kukkala**, a blue team and cloud security engineer.

**Live:** https://akash-xploit.github.io

## Stack

Plain HTML, CSS and JavaScript. No framework or build step.

| File | Purpose |
|---|---|
| `index.html` | Page structure |
| `data.js` | All site content (profile, skills, projects, certifications, …) |
| `script.js` | Rendering and UI behavior |
| `styles.css` | Styles |
| `assets/` | Photo, résumé and images |

## Run locally

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8080
```
